<p align="center">A self-hosted, plugin-based WhatsApp bot with group tools, media utilities, games, status features and a web pairing flow.</p>

## Disclaimer

Use LUKA-XMD responsibly and follow WhatsApp's terms and applicable laws. Get
consent before contacting people or adding the bot to groups and protect the
WhatsApp session credentials and database files created by your installation.
You are responsible for how you deploy and use the bot.

## Features

The repository includes command and feature modules for:

- **Group administration and protections:** group management, greetings and
  restriction features.
- **Media and downloads:** converters, media tools and downloader plugins.
- **AI and chat utilities:** AI plugins, autoreply, notes, reminders and text
  tools.
- **Games and entertainment:** game modules, sports and other fun features.
- **Status handling:** status viewing, reactions and status-saving features.
- **Web pairing and health routes:** a pairing page and a process health check.

## Requirements

- Node.js 22.x and npm 11.x
- A WhatsApp account to link
- FFmpeg for media operations; the Docker image installs FFmpeg and the project
  also includes `ffmpeg-static`

Check your installed versions:

```bash
node --version
npm --version
```

## Quick Start

### 1. Clone and install

```bash
git clone https://github.com/Lukabrand/LUKA-XMD.git
cd LUKA-XMD
npm install --legacy-peer-deps
```

### 2. Configure the session

Set `SESSION_ID` in a root `.env` file or in your hosting provider's environment
settings. The session loader expects the value to start with `LUKA~`.

```env
SESSION_ID=LUKA~your_session_value
BOT_NAME=LUKA-XMD
OWNER_NAME=Lukabrand
OWNER_NUMBER=255768619068
MODE=public
TIME_ZONE=Africa/Nairobi
```

> [!IMPORTANT]
> The current pairing page and pairing service generate IDs prefixed with
> `PANTHER~`, while the session loader accepts only `LUKA~`. As a result, an ID
> generated by the included pairing flow is not accepted by the current startup
> loader. This format mismatch must be resolved before using that ID to start
> the bot.

### 3. Start the bot

```bash
npm start
```

For local startup, the session loader can prompt for a `SESSION_ID` when one is
not configured. Hosted environments require `SESSION_ID` in their environment
configuration.

## Configuration

The project reads environment variables from `.env` and the hosting environment.
Defaults below are defined by the application configuration; settings can also
be stored in the database.

| Variable           | Default          | Description                                                       |
| ------------------ | ---------------- | ----------------------------------------------------------------- |
| `SESSION_ID`       | Empty            | WhatsApp session payload. The loader requires the `LUKA~` prefix. |
| `BOT_NAME`         | `LUKA-XMD`       | Bot display and sticker-pack name.                                |
| `OWNER_NAME`       | `Lukabrand`      | Owner display name.                                               |
| `OWNER_NUMBER`     | `255768619068`   | Owner's WhatsApp number, with country code.                       |
| `BOT_PREFIX`       | `.`              | Prefix used by command configuration.                             |
| `MODE`             | `public`         | Bot operating mode.                                               |
| `TIME_ZONE`        | `Africa/Nairobi` | Time zone used by scheduled and time-based features.              |
| `PORT`             | `5000`           | HTTP server port.                                                 |
| `DATABASE_URL`     | Empty            | PostgreSQL connection URL; when empty, the app uses SQLite.       |
| `AUTO_READ_STATUS` | `true`           | Enable automatic status viewing.                                  |
| `AUTO_LIKE_STATUS` | `true`           | Enable automatic status reactions.                                |
| `AUTO_REACT`       | `false`          | Enable automatic reactions.                                       |
| `AUTO_BIO`         | `true`           | Enable automatic bot bio updates.                                 |
| `AUTO_UPDATE`      | `true`           | Enable the configured repository auto-update behavior.            |

Keep `.env` private. It is ignored by Git, along with common session credential
files and database files.

## Web Routes

| Route              | Purpose                                               |
| ------------------ | ----------------------------------------------------- |
| `/pair`            | WhatsApp pairing page. See the format mismatch above. |
| `/health`          | Returns a JSON health status and process uptime.      |
| `/api/pair`        | Requests a pairing code for a phone number.           |
| `/api/pair/status` | Returns the current pairing status.                   |
| `/api/pair/cancel` | Cancels the current pairing attempt.                  |

## Deployment

The repository includes a Dockerfile, a Heroku app manifest and a Heroku
container configuration. The container runs the web process on port `5000` by
default, installs FFmpeg and uses `npm start`. Heroku configuration declares
`SESSION_ID`, `MODE` and `TIME_ZONE`; provide a valid session value through the
platform's environment settings. See the pairing format warning before
generating or deploying a session.

## Project Structure

| Path               | Purpose                                                                  |
| ------------------ | ------------------------------------------------------------------------ |
| `index.js`         | Starts the HTTP server, database, WhatsApp socket and event handlers.    |
| `luka/connection/` | Socket lifecycle, command loading, serialization and group cache.        |
| `luka/database/`   | Settings, group settings, games, messages and other persistence modules. |
| `luka/handlers/`   | Connection, group, message and status handlers.                          |
| `luka/config/`     | Environment-backed application settings.                                 |
| `lukah/`           | Command modules, plugins and feature modules.                            |
| `lukah/plugins/`   | Categorized plugins, including AI and download tools.                    |
| `luka/pair.html`   | Browser-based WhatsApp pairing interface.                                |
